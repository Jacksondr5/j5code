> **Record.** The register R1–R35 was the definition of record for much of the product until 2026-09-08, when each ruling moved into the definition that owns it. Where each landed: R1–R2, R11, R14–R15 → [archive flow](../product/features/archive-flow.md); R3–R4, R10, R25 → [agent-to-agent communication](../product/a2a/index.md); R5, R26 → [inbox](../product/features/inbox.md); R6 (external systems as nodes) → a door recorded in [shared Squadrons](../product/features/shared-squadrons.md); R7 (cost rolls up per Squadron) → the Fleet page definition when its contract lands; R8, R23 (posture), R28 → [roles](../product/features/roles.md); R9, R29 → [shared Squadrons](../product/features/shared-squadrons.md); R12–R13, R16–R22 → [crews](../product/features/crews.md); R21 (placement) → [squadron](../product/features/squadron.md); R24 → [principles](../product/principles.md); R27 → [playbooks](../product/features/playbooks.md); R30–R35 → [memos](../product/features/memos.md). Kept unedited as the session it was.
