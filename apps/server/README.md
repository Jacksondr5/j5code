# J5 Code

Run the J5 Code server and web client:

```sh
curl -fsSL https://github.com/Jacksondr5/j5code/releases/latest/download/install.sh | sh
j5
```

Use `j5 --help` for CLI options, including pairing and background service setup.

Source and desktop downloads: [Jacksondr5/j5code](https://github.com/Jacksondr5/j5code).
